# Documentation Archive

This directory holds **superseded and aspirational documentation preserved for historical context**. These files are NOT maintained.

The files here describe plans, visions, and platform designs that were either never implemented or have since been removed or replaced (for example, the FastAPI AI service and Supabase, both removed in `CHANGELOG.md` 2.0.0). They frequently contain facts that no longer match the code — outdated framework versions, invented component counts, placeholder repository URLs, mojibake encoding damage, and cross-references to documents that never existed.

**Current truth lives in:**

- `docs/superpowers/specs/` — current design/spec documents
- Root `DESIGN.md`
- Root `AGENTS.md` (architecture and conventions)

Files are archived with their original relative names (e.g. `01-product/PRODUCT-VISION.md` was `docs/01-product/PRODUCT-VISION.md`).

Do not cite these documents as sources of truth, and do not link to them from maintained documentation.
